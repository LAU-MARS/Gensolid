# Gensolid

**English** | [简体中文](README.zh-CN.md)

An open-source boundary-representation (B-rep) modelling kernel benchmarked against Parasolid. Most code is generated by LLM agents in a recursive self-improvement (RSI) loop; correctness is decided by a human-owned verifier.

> Status: **pre-alpha, milestone M0 (verification infrastructure)**. The API will change; do not use in production.

## Design highlights

- **Rust kernel**: the compiler is the first free verifier for LLM-generated code; kernel crates forbid `unsafe`, `unwrap`, and `panic`.
- **PK-style C interface**: integer tags, `GS_<CLASS>_<verb>` naming, option structs with an `o_t_version` field; the Python and WASM bindings share the same semantic layer (`gensolid-api`).
- **Parasolid data model from day one**:
  - analytic surfaces, NURBS, and procedural surfaces coexist; XT round-trips losslessly;
  - topology of body / region / shell / face / loop / fin / edge / vertex, with non-manifold support;
  - per-edge and per-vertex local tolerances (tolerant modelling);
  - topological decisions go through exact predicates and interval arithmetic.
- **XT read/write is a first-class feature.**
- **Verifier first**: the validity checker, policy tests, and differential-testing framework exist before the modelling algorithms; agents are not allowed to modify them.

## What works today

| Crate | Contents |
|---|---|
| `gensolid-core` | Typed ID arena with generations, error codes, session precision and local tolerances |
| `gensolid-math` | Points/vectors/frames, outward-rounded interval arithmetic, exact `orient2d` / `orient3d` |
| `gensolid-geom` | Lines, circles, ellipses, B-spline curves; planes, cylinders, cones, spheres, tori, B-spline surfaces; extruded and revolved surfaces; evaluation, derivatives, point-to-curve/surface distance |
| `gensolid-topo` | Non-manifold topology model, block primitive |
| `gensolid-check` | Validity checks (topological consistency, loop closure, manifold edges, points lying on curves/surfaces within tolerance) |
| `gensolid-xt` | XT text-header read/write, node-stream tokenizer (**tested against synthetic samples only; needs validation against real XT files**) |
| `gensolid-api` | PK-style session and tag API |
| `gensolid-ffi` | C ABI and header `crates/gensolid-ffi/include/gensolid.h` |
| `bindings/python`, `bindings/wasm` | Python (PyO3) and WebAssembly bindings |
| `verifier/policy` | Repository policy tests (no literal tolerances, B-rep must not depend on mesh, `unsafe` only in FFI, etc.) |

## Building

Requires Rust 1.88+.

```sh
cargo test                                   # kernel + policy tests
cargo clippy --workspace --all-targets -- -D warnings
cargo build -p gensolid-wasm --target wasm32-unknown-unknown --release
pip install maturin && maturin develop -m bindings/python/Cargo.toml
```

Python:

```python
import gensolid
s = gensolid.Session()
body = s.body_create_solid_block(1.0, 2.0, 3.0)
assert len(s.body_ask_faces(body)) == 6 and s.body_check(body) == []
```

C: see `crates/gensolid-ffi/examples/block.c`.

## Roadmap

| Milestone | Theme | Acceptance metric |
|---|---|---|
| M0 | Verification infrastructure: checkers, XT/STEP reading, OCCT differential testing, benchmark suite, private test set | Validity report on real XT files |
| M1 | Geometry core: intersections, projection, full exact-predicate coverage | Surface-intersection branch coverage |
| M2 | Topology and basic modelling: Euler operators, extrude/revolve/sweep/loft, mass properties, tessellation | Mass-property error |
| M3 | Boolean operations (analytic surfaces → NURBS → tolerant → non-manifold) | Boolean success rate on randomly rotated model pairs |
| M4 | Fillets, chamfers, shelling, offsets, direct modelling | Fillet-chain success rate |
| M5 | XT writing, STEP AP242, sewing and healing | XT round-trip opens in Parasolid-based applications |
| M6 | Convergent modelling (mesh bodies), PK-style API coverage | Coverage against the Parasolid feature list |

Design decisions are recorded in [`docs/adr/`](docs/adr/); rules for agent development are in [`AGENTS.md`](AGENTS.md).

## Acknowledgements & licence

Gensolid stands on the shoulders of the following projects and literature.

### Core references

#### Open CASCADE Technology (OCCT)

<https://github.com/Open-Cascade-SAS/OCCT> · LGPL-2.1 with the Open CASCADE exception

Gensolid's primary open-source reference. We study OCCT's architecture, algorithm design, and documentation, and use it as a differential-testing oracle (run as a separate process by the verifier, comparing results on the same inputs).

Because OCCT is LGPL while Gensolid is Apache-2.0, Gensolid's source **contains no** code translated or adapted from OCCT, and does not link against OCCT. Algorithms are implemented independently from public literature and from OCCT's documentation and black-box behaviour. The rules are recorded in [`docs/adr/0007-references-and-provenance.md`](docs/adr/0007-references-and-provenance.md).

#### truck

<https://github.com/ricosjp/truck> · Apache-2.0 · RICOS Co. Ltd. and the truck contributors

A Rust B-rep kernel, and the reference for Gensolid's NURBS implementation. truck's licence is compatible with Gensolid's; any code ported from truck notes the source repository and commit in its file header and retains the copyright notice in [`NOTICE`](NOTICE).

### Specifications & literature

- Siemens, *Parasolid XT Format Reference* — the format basis for XT reading and writing. Siemens publishes the specification so that third parties can write converters.
- L. Piegl, W. Tiller, *The NURBS Book*, 2nd ed., Springer, 1997 — B-spline basis functions and evaluation algorithms (A2.1, A2.3).
- J. R. Shewchuk, *Adaptive Precision Floating-Point Arithmetic and Fast Robust Geometric Predicates*, Discrete & Computational Geometry 18, 1997 — exact predicates.
