# 旋转、放样、一般 NURBS 求交与 Viewer

本页记录 2026-10-13 新增实现的实际范围。固定 M1 目录仍是 1088/1088；这个数字不代表任意曲面组合均已解决。一般曲面—曲面求交的全局分支连接认证仍未完成。

## 人工检查入口

在仓库根目录运行：

```sh
python tools/viewer.py
```

打开 `http://127.0.0.1:8765`。需要 Rust/Cargo、Python 3 和浏览器，无 npm、CDN 或第三方 Python 依赖。启动脚本自动构建 Rust 场景程序；已构建时可用 `--no-build`。服务仅监听本机，可用 `--port` 改端口；终端 Ctrl+C 停止。

五个场景分别演示旋转实体、多截面实体放样、光滑 NURBS 曲面放样、曲线—曲面求交、曲面—曲面求交。拖动旋转、滚轮缩放；聚焦画布后方向键旋转、加减键缩放。可切换显示面、透视线和参考网格，导出含输入、显示几何、检查指标的 JSON。透视线包含被面遮挡的边，便于检查共享拓扑。导出的 `request` 可直接输入 `gensolid-viewer` 重现：

```sh
echo '{"scene":"revolve","angle":180}' | cargo run -p gensolid-viewer
python tools/benchmark-advanced.py
```

绿色仅用于完整 B-rep 检查通过或曲线—曲面全域根认证；光滑放样曲面没有实体通过标记；数值交线为黄色候选。显示网格按参数网格采样，没有弦高认证，绝不参与内核建模或求交。

## 实现与限制

| 功能 | 已实现 | 明确限制 |
|---|---|---|
| 旋转实体 | 凸的 `(半径, 高度)` 闭合多边形，任意刚性坐标系，正角度部分/整周旋转；有理二次圆弧和 NURBS 面，共享边、封盖、闭壳 | 所有半径须大于线性精度；轴上极点、穿轴、凹轮廓和任意曲线轮廓尚不支持 |
| 多截面实体放样 | 各截面独立改变形状、偏移、旋转；逐段双线性 NURBS 侧面和封盖；全段区间凸性检查 | 平行截面、严格递增高度、凸多边形、相同顶点数和明确对应关系；不是任意闭合曲线的光滑实体放样 |
| 光滑 NURBS 曲面放样 | 2～64 条兼容有理曲线的齐次全局插值；V 次数可选，逐截面插值 | U 次数、节点及控制点数须兼容；不自动统一节点/升阶；非正权重、病态系统拒绝；不封装成实体 |
| NURBS 曲线—曲面 | 任意次数、正权重、多节点跨度；原始参数方程上的区间排除、Krawczyk 存在唯一性证明、根位置误差上界 | 相切、重合、边界根、极端权重及资源耗尽可返回未解决区域；只有全域无未解决区域才返回完整 `IntersectionSet` |
| NURBS 曲面—曲面 | 任意次数和正权重；全参数域区间排除及可能交集覆盖、原始方程的数值预测/校正追踪；相同表示重合和空交集认证 | 非空交线的完整分支数、连接关系、小环及奇异点拓扑未认证；不把数值折线冒充精确 B-rep 边 |

旋转/实体放样的 checked 入口位于 `gensolid-modeling`，返回前运行不可修改的 `check_body` 并要求没有未检查项；Rust `Session` 提供同名方法。C/Python/WASM 接口本轮未扩展。新曲面实体的质量属性和认证网格仍不支持；已有平面实体质量属性及解析参数面片认证网格能力不变。

`gensolid_geom::loft::loft_nurbs_sections` 提供光滑曲面；`nurbs_intersect::intersect_nurbs_curve_surface` 返回根证书及未解决区域；`nurbs_surface_intersect::intersect_nurbs_surfaces` 返回数值候选曲线和可能交集覆盖。后者的空交集和相同表示重合接入精确分派器，非空未认证情形保持 `ErrorCode::Unimplemented`。裸拓扑构建函数与既有构建器一样，应通过 checked 层使用。

## 公开证据

运行 `python tools/benchmark-advanced.py` 得到 `target/advanced-development-report.json`：12/12 开发探针通过。

- 10°、180°、360° 旋转和 2、4、6 截面实体放样：6/6 完整检查通过，缺陷和未检查项均为 0。
- 三组光滑放样：最大截面残差约 `1.09e-15`。
- 五次曲线 × 双三次非平面 NURBS：3 个认证根，0 个未解决区域，最大残差约 `1.35e-12`，最大位置误差上界约 `1.57e-12`。
- 两组曲面闭合交线：对独立解析圆的最大采样误差约 `9.01e-11`。这只验证返回样本的精度，不能充当分支完整性证明。

新增性质测试覆盖随机尺寸/坐标系、近退化输入拒绝、多跨度有理曲线随机权重、求交预算耗尽和重合情况。公开主基准重跑输出 `target/m0-m1-m2-advanced-report.json`：M1 固定 24/24、随机及扩展 1088/1088；M2 已有 48/48 实体检查、48/48 OCCT 质量属性对拍、48/48 平面网格和 3/3 解析面片网格。冻结输入 22 个文件均通过完整性检查；M0 原有 12/13 OCCT 检查一致率及明确失败/不支持项原样保留。

新曲面实体尚无 OCCT 质量属性误差结果。私有验收接口继续预留，本轮未运行私有集。上述报告是公开开发证据，不声明完整 M1/M2 或 L0 验收。

## 数学来源与代码来源

实现为项目原创；没有翻译或适配 OCCT 源码，也没有复制 Parasolid 手册文字。数学背景参考 MIT 的 [曲面求交细分法](https://web.mit.edu/hyperbook/Patrikalakis-Maekawa-Cho/node108.html)、[区间算术](https://web.mit.edu/hyperbook/Patrikalakis-Maekawa-Cho/node45.html) 及 Rump 的 [验证数值计算与 Krawczyk 方法](https://www.tuhh.de/ti3/rump/Research_Rump/topics.shtml)。这些来源也说明：残差小不等于全局交线拓扑完整。
