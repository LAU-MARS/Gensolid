# ADR 0003：从第一天就按 Parasolid 数据模型设计

状态：已采纳（2026-10-12）

## 背景

非流形拓扑、容差和过程曲面如果事后再补，几乎需要重写整个内核。XT 文件要能无损往返，内核的实体也必须与 XT 节点一一对应。

## 决定

### 几何

| 类别 | 曲线 | 曲面 |
|---|---|---|
| 解析 | 直线、圆、椭圆 | 平面、圆柱、圆锥、球、环面 |
| 自由曲面 | B 样条曲线（NURBS） | B 样条曲面（NURBS） |
| 过程 | 计划：SP 曲线、裁剪曲线、交线 | 拉伸面、旋转面；计划：偏置面、圆角面 |

- 解析几何不转成 NURBS，以保持精度和 XT 等价性。这一点与 Zoo 的“全部 B 样条”路线不同。
- 过程几何通过 ID 引用其他几何，所有几何都存在 `GeomStore` 中。只能引用已存在的几何，因此引用图天然无环。

### 拓扑

```text
Body ─┬─ Region ── Shell ─┬─ Face ── Loop ── Fin ── Edge ── Vertex
      │                   ├─ 线框边
      │                   └─ 孤立顶点
      └─ regions[0] 永远是无限大的空区域
```

- 边可以有任意多个 fin，按径向排序（非流形）。
- 面分隔 front 壳和 back 壳，一个体可以有多个实体区域和空区域（胞元体）。
- `BodyKind` 有 acorn / wire / sheet / solid / general 五种，规定一个体允许包含什么。

### 容差

边和顶点可带 `Tolerance`；不带时为精确实体，容差等于会话线性精度的一半（见 ADR 0004）。

## 后果

- 模型比半边结构复杂，但 XT 导入后可以原样表示，导出时也无需近似。
- 底层的 `RawEditor` 可以构造任意（包括非法）拓扑，供建模操作和文件读取使用；交给调用方之前必须通过 `check_body`。
