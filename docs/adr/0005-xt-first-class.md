# ADR 0005：XT 读写是一等功能

状态：已采纳（2026-10-12）

## 背景

XT 是 Parasolid 的原生格式，西门子公开了格式规范，目的是让第三方编写转换器。能直接读写 XT，意味着可以与数百款 Parasolid 应用互通，也能拿真实的工业模型做测试。ABC 等公开数据集的 STEP 文件也是从 Parasolid 模型转出来的。

## 决定

- `gensolid-xt` 与建模算法同等优先，并随数据模型同步演进。
- 分阶段实现：
  1. 文本头和传输前导（已完成，目前只用合成样例测试过）；
  2. 文本节点流按 schema 解码；
  3. 二进制 `.x_b`；
  4. 写出模型。
- 读取的结果用 `RawEditor` 建立拓扑，然后必须通过 `check_body`。导入失败时报告具体节点，不做静默修复。
- 写出的文件用免费的 JT2Go 查看器人工抽检；如能取得 Parasolid 授权，再用它做自动校验。
- 参考开源实现 `parasolid_core`、`xt-parser` 的格式理解，但遵守各自的许可证。

## 后果

- 验证器语料库需要尽快收集真实 `.x_t` / `.x_b` 文件（许可证允许再分发的放公开语料，其余放私有语料）。
- XT schema 随 Parasolid 版本变化，解码器必须由 schema 驱动，不能写死字段位置。
