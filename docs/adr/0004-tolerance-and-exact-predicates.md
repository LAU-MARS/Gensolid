# ADR 0004：容差建模加精确谓词

状态：已采纳（2026-10-12）

## 背景

社区对 AI 生成内核最常见的批评是“容差写死成常量”。导入的数据精度往往比本内核低，需要容差建模；但仅靠容差做拓扑判定又会前后矛盾。精确谓词和容差追踪解决的是不同问题，两者都需要。

## 决定

1. **会话精度 `Precision`**：线性精度 1e-8，角度精度 1e-11 弧度，尺寸盒 1000，与主流商业内核同一数量级。所有阈值都由它推导，例如 `default_local()`、`solver()`、`degenerate_length()`。
2. **局部容差 `Tolerance`**：附在边和顶点上，只增不减；不小于默认局部容差。检查器按“顶点容差 + 边容差”判断点、线、面是否一致。
3. **精确谓词**：`orient2d` / `orient3d` 用 Shewchuk 的自适应精度算法（`robust` crate），结果等于无限精度下行列式的符号。
4. **区间算术**：`Interval` 每次运算后向外扩一个 ulp，保证包含精确值，并给出“确定符号或无法判定”。
5. **判定顺序**：先用精确谓词或区间算术；都无法判定时才回退到容差，并在代码里显式写出这一步。
6. **字面量容差只能出现在 `crates/gensolid-core/src/tolerance.rs`**，由 `verifier/policy` 检查。

## 后果

- 每个几何操作都要说明它把误差累加到了哪个实体的容差里。这一点会在实现布尔和圆角时（M3、M4）细化为单独的 ADR。
- 数值迭代用 `Precision::solver()` 作为收敛阈值，曲线、曲面投影采用带回溯线搜索的 Gauss-Newton，保证距离单调下降。
