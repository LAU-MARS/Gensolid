# 曲面几何接入拓扑：当前实现范围

这批实现把 SMLib 的几何候选接入 Gensolid 的 checked 建模入口。已经可以构造曲面片体、构造受限曲面实体，并在已有旋转／放样实体上分割完整参数矩形面、更新相邻面的共享边。**尚未形成任意曲面实体的“分割 → 布尔 → 偏置／抽壳”通用闭环。** 后三个阶段当前主要支持凸平面实体，不能将这些能力理解为对前面所有曲面结果都适用。

## 支持矩阵

| 阶段 | Rust `Session` 入口 | 当前接受的范围 |
|---|---|---|
| 曲面片体 | `body_create_sheet_surface`、`body_create_sheet_backend` | 正权重 NURBS 自然参数矩形；须通过全域图面正则性、单射性充分条件；不接受任意裁剪环、周期接缝、奇异极点 |
| 受限曲面实体 | `body_create_solid_surface_prism`、`body_create_solid_backend_prism` | 图面与沿投影法向平移的副本及直纹侧面构成闭壳；这是定向棱柱，不是曲面等距偏置 |
| 面分割与邻接更新 | `body_split_face_isoparametric` | 完整矩形 NURBS 面，分割方向为单个 Bezier 跨度；原边按拓扑身份同步分割，更新相邻 fin 的参数曲线；单壳实体或片体 |
| 有界面求交驱动分割 | `body_split_face_by_sheet` | 直纹 NURBS 的等参横截交线；另支持多项式 Bezier 挤出曲面与斜平面的非等参交线，保留原载体、构造两条 UV 裁剪环。工具须为凸平面四边形，目标控制包投影严格位于工具内部；小工具、一般有理非等参分支、相切、闭环及再次分割已有非矩形裁剪面不支持 |
| 提取与缝合 | `body_extract_sheets`、`body_sew_sheets` | 提取单环、有限端点的支持面；缝合完整、有向的凸平面壳。一般曲面缝合未实现 |
| 布尔 | `body_boolean` | 两个凸平面实体的并／交／差；去除内部界面，按材料连通分量返回实体，保留有限空腔 region；共面外表细分面可保留 |
| 布尔单元分解 | `body_boolean_cells` | 返回内部互不重叠的凸单元；相邻单元的内部界面保留，不能当作已融合的布尔边界 |
| 曲面片体偏置 | `body_offset_sheet_backend` | 自然矩形平面 NURBS；独立控制系数误差界验证 SMLib 输出，支持同有理基表示及仿射平面的多项式升阶表示；一般曲面法向偏置未实现 |
| 实体偏置 | `body_offset_planar` | 凸平面实体、每个顶点三面相交、偏置后面邻接不变；拒绝塌陷、翻转及需要拓扑事件处理的情况 |
| 封闭空腔／开口抽壳 | `body_hollow_planar`、`body_shell_planar` | 同上；前者建立有限空 region，后者删除一个面并构造连接内外边界的口沿；一般曲面抽壳未实现 |

布尔结果可能是非凸实体；当前布尔输入限定为凸体，因此不能承诺结果可继续任意链式布尔。质量属性目前仍限定于现有受支持的平面边界。

## 几何、验证与拓扑的责任

`gensolid-geom::backend::GeometryBackend` 只返回拥有自身数据的曲面或交线候选。SMLib adapter 实现该接口；依赖方向保持 `ffi → api → modeling → geom`。调用时借用 backend，`Session` 不保存 native `Rc`，仍可跨线程转移；native handles 本身仍不可跨线程共享。

SMLib 的成功状态、交线采样残差和 reported deviation 都不是全域正确性证明。当前直纹面分割独立验证控制系数、横截方向和有限工具范围，再构造原 NURBS 面的精确等参曲线、配对 UV 曲线及共享拓扑。空候选不被解释为认证的空交集。程序型 offset 曲面通过显式 `approximate_nurbs` 转换后，还须通过内核的整体误差界检查。

非等参挤出面分割利用 `S(t,v)=P(t)+vD`：沿挤出方向投影曲线控制点到工具平面，得到空间交线及 UV 曲线的 Bernstein 系数。区间运算验证整个参数域的横截性、UV 单调性、参数曲线提升误差和到真实交线的距离上界；浮点表示引入的挤出误差计入预算。SMLib 若被调用，其交线仍只是候选，实际边界由这些独立几何关系重建。该路径当前限定单个多项式 Bezier 跨度、次数不超过 16。

`FinGeometry` 保存每个 fin 的参数曲线及对应 edge 参数区间；同一 edge 在两个面上的 UV 表示彼此独立。已有线边 Euler 分割拒绝带有显式参数曲线的 fin，防止产生过时的 UV 元数据。新操作在提交前运行未修改的 `check_body`；参数曲线一致性另有回归测试，不能声称现有 checker 已覆盖全部 UV 不变量。

操作返回新 body，保留输入。`Model::transaction` 和 Session staging 在失败时撤销几何、拓扑和 tag 变更；目前通过完整快照复制实现，较大模型的时间和内存成本需要后续优化。尚不支持的几何返回明确错误，不输出猜测的可用实体。

## 运行

默认 Rust 回归不依赖 SMLib：

```sh
cargo test -p gensolid-modeling --test surface_pipeline
```

按 [SMLib 构建说明](smlib.md) 设置源码和构建目录后：

```sh
cargo test -p gensolid-ffi --features smlib
cargo run -p gensolid-ffi --features smlib --example smlib_modeling
```

示例演示真实 SMLib 曲面构造、受限曲面实体、有界求交分割与 backend 释放后的 body 检查，再用平面实体演示缝合、融合布尔、偏置、封闭空腔和开口抽壳。它明确使用两组输入，不把平面算法包装成通用曲面算法。

管线回归共 18 项，覆盖随机尺寸、坐标系、独立旋转的凸体布尔体积守恒、已有旋转／放样实体分割、连续编辑的共享边和参数曲线、非等参裁剪的 U/V 互换与非单位参数域、近边界拒绝、偏置翻转拒绝及错误回滚。近相切用例要求空间交线误差界，不能仅凭平面残差通过。另有 Session 分配拓扑与 tag 后失败的回滚测试，验证后续 ID 分配与未尝试失败操作的对照 Session 一致。

3 项 native 建模集成测试验证真实 SMLib 的等参分割、非等参分割和平面片体偏置；原有 11 项 native 几何测试继续保留。此处没有新增 Parasolid／OCCT 对拍或私有验收结论。

本轮入口位于 Rust Session；C、Python、浏览器建模接口尚未增加这些操作，既有单 Wasm 可行性验证不代表新建模接口已经在浏览器验收。

## 后续通用化仍需完成的工作

1. 一般有理曲面的非等参交线全域分支连接、相切／奇异事件、周期接缝和闭合交线处理。
2. 任意 UV 裁剪环的交点排序、面内区域分类、多环分割，以及几何容差一致的共享边维护。
3. 一般曲面壳的交叠／自交检查、缝合、材料分类和布尔后的拓扑重建。
4. 曲面法向偏置的独立全域误差界、自交消解、消失面／短边等拓扑事件及多面抽壳连接。
